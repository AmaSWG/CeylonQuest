**CeylonQuest**



CeylonQuest is a web-based tourism platform designed to help local and international tourists discover and experience Sri Lanka through a single platform.



The system allows users to explore destinations, activities, and tour packages, make bookings, and complete payments online.



**Objectives:**

* Provide a centralized platform for Sri Lankan tourism.
* Help tourists discover destinations and activities.
* Allow users to browse and book tour packages.
* Provide secure online payment functionality.
* Provide management features for administrators and service providers.
* Develop the system using a scalable microservices architecture.



**Project Scope:**

* User registration and authentication
* Destination management
* Activity management
* Tour package management
* Search and filtering
* Booking management
* Payment processing
* User and admin management
* Dynamic reports



**User Roles:**

**Tourist:**

Browse destinations and activities

View tour packages

Search and filter services

Make and manage bookings

Make payments

**Service Provider:**

Manage tourism services

Manage availability and pricing

View bookings

**Administrator:**

Manage users and tourism content

Monitor bookings and payments

View reports



**Main Features:**
